# Welcome to PointMatter AI Repo

This repository contains the PointMatter AI-enabled portal applications and supporting tools.

## Repository Structure

- **portal/** - Angular-based portal applications
- **PointMetrics/** - Metrics and monitoring modules
- **pmvp-1t1/** through **pmvp-1t5/** - Various portal versions and prototypes
- **flatten/** - Utilities for flattening/unflattening codebase

## Flattened Codebase Analysis

The repository includes a comprehensive analysis of the flattened Angular application codebase. This analysis provides insights into:

- Project structure and statistics
- Technology stack and dependencies
- Code patterns and architecture
- File distribution and metrics
